# 🍔 Turbo Tastes – Food Web App

Turbo Tastes is a modern food web application built with React and Tailwind CSS. It offers a smooth and responsive user experience for browsing delicious food items, adding them to cart, and exploring culinary content.

# 🚀 Features

🛒 Add to Cart functionality
📱 Fully responsive design (mobile + desktop)
⚡ Fast performance using Vite + React
🎨 Styled with Tailwind CSS
🔐 Authentication integration (Auth0)
🧾 Dynamic food items listing
🧩 Reusable components architecture

# 🛠️ Tech Stack

Frontend: React.js
Styling: Tailwind CSS
Routing: React Router
State Management: Context API
Auth: Auth0
Build Tool: Vite
